Changer's Dawn FPS v0.8.0 - portal edition
==========================================
Upload the whole folder contents (index.html, music/, lib/) as the game build.
index.html must stay at the top level. Total size is about 13 MB; the page itself is about 7 MB.

Optional speed-up: put three.min.js (r128) in lib/ - see lib/README.txt.
Music streams from music/ after the game starts, so it no longer slows the first load.
If a music file is missing the game simply plays without it.
